# OPSTYIX-toolkit

OPSTYIX Toolkit is a Blender addon built for animators working to music. It provides tools to sync timeline markers and keyframes to a BPM with some optional randomization. If you happen to use Octane for Blender, this addon also includes a scatter surface builder and a solo tool for previewing textures. As of now this addon contains the following modules that can be enabled/disabled in the preferences:

 - Beat Markers / Animation Bookmarks
 - Automated Keyframer
 - Octane Render Texture Solo Viewer
 - Octane Scatter Setup
